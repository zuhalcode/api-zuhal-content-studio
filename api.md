## API Endpoints

### Capitals

| Method | Endpoint         | Deskripsi                |
| ------ | ---------------- | ------------------------ |
| GET    | `/capitals`      | Ambil semua data capital |
| GET    | `/capitals/{id}` | Ambil satu data capital  |
| POST   | `/capitals`      | Tambah data capital baru |
| PUT    | `/capitals/{id}` | Perbarui data capital    |
| DELETE | `/capitals/{id}` | Hapus data capital       |

### Daily Transactions

| Method | Endpoint                   | Deskripsi                    |
| ------ | -------------------------- | ---------------------------- |
| GET    | `/daily-transactions`      | Ambil semua transaksi harian |
| GET    | `/daily-transactions/{id}` | Ambil satu transaksi harian  |
| POST   | `/daily-transactions`      | Tambah transaksi harian baru |
| PUT    | `/daily-transactions/{id}` | Perbarui transaksi harian    |
| DELETE | `/daily-transactions/{id}` | Hapus transaksi harian       |
